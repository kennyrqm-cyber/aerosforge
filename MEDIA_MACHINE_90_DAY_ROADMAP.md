# AEROSFORGE — 90-Day Media Machine Roadmap

## Phase 1 — Foundation (Days 1–30)
**Objective:** establish a recognizable voice and repeatable production engine.

- Finish production packages for Lessons 02–10.
- Build a reusable script/shot/thumbnail/quiz/Gauntlet template library.
- Publish consistently only after rights, originality, factual, and safety gates clear.
- Establish baseline analytics for retention, CTR, learning conversion, and return behavior.
- Launch signature series tests across short-form and long-form formats.
- Build an authoritative source registry for every published lesson.

**Kill criteria:** no publishing volume target overrides safety or rights review.

## Phase 2 — Distribution (Days 31–60)
**Objective:** turn every master lesson into a distribution package.

Per flagship lesson target:
- 1 long-form video
- 3–5 short-form cuts
- 1 carousel
- 1 quiz package
- 1 Gauntlet scenario
- 1 oral-exam challenge
- 1 community prompt
- 1 Academy lesson update

Test packaging aggressively while keeping the educational core stable.

## Phase 3 — Conversion (Days 61–90)
**Objective:** make the media engine feed the product.

- Optimize Short → Academy → Gauntlet → Pilot Passport flow.
- Add stronger end-screen and description CTAs.
- Build lead capture for CFI and flight-school interest.
- Create recurring “Zero to Helicopter Pilot” pathways.
- Start building instructor/community feedback loops.
- Identify the first 3 formats with the strongest qualified-learning conversion and allocate more production capacity to them.

## Weekly operating rhythm
**Monday:** research + source/rights audit
**Tuesday:** scripting + technical review
**Wednesday:** production/editing
**Thursday:** safety/originality/fact review
**Friday:** publish/schedule + analytics review
**Weekend:** community prompts + idea mining

## Strategic doctrine
AEROSFORGE is not a content dump. Every piece must have a job:
**Attract → Teach → Challenge → Identify → Progress → Return.**

The machine wins when audience growth and actual learning growth happen together.
