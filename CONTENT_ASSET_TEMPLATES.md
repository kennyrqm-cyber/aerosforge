# AEROSFORGE Content Asset Templates

## 1. Long-form video
- Asset ID
- Lesson ID
- Series
- Audience
- Learning objective
- Hook
- 3–7 teaching beats
- Demonstration/visual plan
- Knowledge check
- Safety boundary
- CTA: Academy → Gauntlet → Pilot Passport
- Primary sources
- Rights status
- Fact-check status
- Safety review
- Human approval

## 2. Short-form video
**0–2 sec:** pattern interrupt
**2–8 sec:** question/problem
**8–35 sec:** original explanation
**35–50 sec:** reveal/decision
**50–60 sec:** CTA

Never sacrifice factual accuracy for a stronger hook.

## 3. Gauntlet scenario
- Situation
- What the learner knows
- What the learner does not know
- Decision options
- Best educational decision
- Why
- Common trap
- Learning objective
- Aircraft-specific disclaimer where applicable
- Source IDs

## 4. Carousel
Slide 1: challenge/question
Slide 2: misconception
Slides 3–6: concept progression
Slide 7: knowledge check
Slide 8: CTA

## 5. Quiz
- Question
- 4 options
- Correct answer
- Explanation
- Distractor rationale
- Difficulty
- Source IDs

## 6. Oral exam
- Examiner prompt
- What a strong answer should cover
- Follow-up question
- Common weak answer
- Safety boundary

## 7. Community prompt
- One provocative but honest question
- One educational framing sentence
- One invitation to explain reasoning
- No rage bait
- No fabricated incidents

## Production gate
DRAFT → SOURCE CHECK → ORIGINALITY CHECK → RIGHTS CHECK → FACT CHECK → SAFETY REVIEW → HUMAN APPROVAL → SCHEDULED/PUBLISHED.

A missing gate is a stop signal, not an inconvenience.
