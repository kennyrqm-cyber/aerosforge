# AEROSFORGE™ Content Factory

The AEROSFORGE media machine turns the 30-lesson Academy curriculum into original, rights-aware aviation education.

## Production rule
Research → synthesize → create original expression → cite authoritative sources → rights check → safety check → human approval → publish.

## Asset families
Each lesson can generate a master lesson, long-form video, Shorts/Reels/TikToks, carousel, quiz, Gauntlet scenario, oral-exam challenge, community prompt, article, email, and Pilot Passport challenge.

## Hard stop
Unknown rights, copied expression, unverified aviation claims, unsafe instructions, or missing human review = DO NOT PUBLISH.

## First production sprint
Lesson 01 — Helicopter Fundamentals is the reference package. Replicate its structure across Lessons 02–30, then batch-produce by series.
